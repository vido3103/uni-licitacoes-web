# UNI Web — Blindagem da Fundação C1–C10

Data: 2026-09-11
Status: **APROVADA PARA INÍCIO DAS IMPLEMENTAÇÕES**

## Resultado

- C1 — RLS e isolamento multi-cliente: aprovado.
- C2 — RPCs SECURITY DEFINER expostas: corrigido; nenhuma função `public` SECURITY DEFINER executável por `authenticated` permanece.
- C3 — Menor privilégio: aprovado; zero grants de tabelas `public` para `anon` e zero TRUNCATE/TRIGGER/REFERENCES para `authenticated`.
- C4 — Cliente A × Cliente B: aprovado em teste transacional com rollback.
- C5 — Auditoria/histórico: `audit_events`, `ai_executions` e `operational_readiness_history` protegidas como append-only.
- C6 — Storage/documentos: buckets privados; isolamento por cliente validado; sobrescrita física de `client-documents` removida; hard-delete de metadados de documentos do cliente removido para preservar versionamento/histórico.
- C7 — Auth/credenciais: configuração pública do navegador somente por variáveis de ambiente; nenhum fallback de chave no código; `.env*` ignorado no Git, com exceção do `.env.example`; nenhum `SUPABASE_SERVICE_ROLE_KEY` encontrado no repositório.
- C8 — Índices: 48 avisos informativos de índices ainda não utilizados mantidos por decisão conservadora durante desenvolvimento.
- C9 — Contratos finais: zero tabelas `public` sem RLS; zero grants `anon`; zero grants elevados para `authenticated`; zero views públicas sem `security_invoker`; zero buckets públicos; zero RPC pública SECURITY DEFINER executável por `authenticated`; build de produção Vercel aprovado.
- C10 — Blindagem final: concluída com uma ressalva de plano abaixo.

## Ressalva conhecida

O advisor de segurança mantém somente `auth_leaked_password_protection`: proteção contra senhas vazadas desabilitada. O projeto Supabase está no plano Free e a própria documentação do Supabase informa que esse recurso está disponível no plano Pro ou superior. Não foi realizado upgrade de custo nesta blindagem.

Essa ressalva não representa regressão de código e não impede o início das implementações aprovadas. Deve ser reavaliada se o projeto migrar para plano Pro antes da abertura ampla a clientes.

## Gate

A fundação está liberada para iniciar I1–I12, mantendo a ordem aprovada e sem reverter as proteções C1–C10.
