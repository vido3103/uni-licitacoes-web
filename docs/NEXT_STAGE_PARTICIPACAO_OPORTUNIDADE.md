# Próxima etapa — Participação por Oportunidade

Após a aprovação do Gate de Participação em produção, o próximo bloco é integrar esse Gate à decisão por oportunidade.

Objetivo: nenhuma oportunidade pode avançar para preparação de participação, CFP/proposta/disputa sem combinar o Gate vigente da empresa/capacidade com a análise específica do edital, requisitos da oportunidade e decisão rastreável.

Este documento apenas registra a fronteira de etapa; a implementação deve ocorrer em branch própria com validação, blindagem e revisão comprobatória antes de promoção.
